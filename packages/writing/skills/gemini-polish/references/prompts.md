# Gemini 润色提示词模板

以下为提交模板，花括号内容需根据当前文件替换；删除不适用的分支。具体研究边界来自本次原稿和项目要求，不照搬其他课题。

## 首次全局说明

```text
请在这个新对话中润色《{文稿名称}》，受众是{受众}，用途是{口头汇报/书面正文}。
我会按{阶段清单}依次提交，按内容逻辑划分，不按固定页数切分。

目标是{语体、篇幅或时长目标}，改善表达和衔接，保持原有实质内容。
保留章节/页码和原题名，输出完整正文，不用提纲代替。
保持事实、数值、引用、研究范围、方法含义、证据强度及评价条件不变。
区分已完成和拟开展工作，不新增文献、数据、能力或性能承诺。
事实疑点单列在批次正文之后，不擅自写成新的事实。

统一术语：{术语及必要的概念区别}
必须保留的条件：{研究边界、统计规则及其他约束}
文章/汇报结构：{各部分职责，哪些内容留到后文}

{PPT适用：按实际页面顺序和布局讲解，核心关键词与页面一致。
指图动作放括号内，正文可直接照读。来源、图片提示词及内部便笺不作为口播。
输出格式为“## 第N页 原题名”后接完整口播。}

请先简短确认理解，等待第一批材料；后续每批直接润色，不要求逐批确认。
```

## 阶段提交

```text
当前阶段：{名称及页码/章节范围}
承接背景：{前一阶段的结论；下一阶段将进入什么主题}
本批必须保留：{事实、限定条件、术语差别}

{逐页/逐章节重复：编号、原题名、原稿。
PPT另附页面要点、布局与图像内容；注明截图或文字布局说明的实际提供情况。}

请按原顺序输出本批全部正文。核对问题统一放在本批正文之后。
```

## 定点返修

```text
请返修{具体范围}：
{位置}：当前表述“{原句}”存在{问题}。
核验依据是{原稿/页面/报告中的具体内容}，应保留{准确含义及条件}。

请{完整重发受影响批次/仅返回编号、需替换原句和修订句}。
其他已经核对的内容保持不变，不扩写。说明放在正文之外。
```

## 跨阶段终审

```text
以下是合并稿{或本次待检查的相邻阶段}、统一术语及已核实的条件。
{材料}

请检查段间衔接、重复或跳步、概念一致性、已有与拟开展工作的区别及必要限定是否完整。
只列真正需要修改的“页码/章节＋需替换原句或段落＋建议修订”，不要重新生成全稿。
不确定事实单列疑点，不能通过润色提高结论强度。
```
